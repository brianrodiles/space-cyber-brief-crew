# Space Cyber Brief Crew

AI-powered multi-agent cyber threat intelligence pipeline built with CrewAI.

## What it does

This project builds an automated threat intelligence briefing system that:

- Collects cyber and space security signals
- Uses multiple AI agents to analyze threats
- Generates daily intelligence briefs
- Supports monitoring of emerging threats to space systems and critical infrastructure

## Tech Stack

- Python
- CrewAI
- OpenAI
- OSINT feeds
- Multi-agent orchestration
